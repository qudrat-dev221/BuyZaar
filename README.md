BuyZaar is a fully functional e-commerce single-page application (SPA) built entirely with Vanilla JavaScript, HTML, CSS, Bootstrap, and JSON — without using any external frameworks.

It showcases core front-end engineering principles like custom routing, component-based UI rendering, and state management through LocalStorage.

The project features complete add-to-cart, checkout, and product detail functionalities, along with a responsive design optimized for all devices.

BuyZaar demonstrates clean, scalable, and framework-independent JavaScript architecture — highlighting strong command over web fundamentals and interactive UI design.
